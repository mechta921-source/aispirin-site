## Страница ALMA™ — особо

`/alma/` — промо-лендинг персонального AI-помощника ALMA. На странице встроено промо-видео (~45 сек, формат 9:16), которое создано **целиком AI-инструментами**:
- **Seedance 2** (polza.ai) — генерация видеоклипов по референсу лица
- **Яндекс SpeechKit** — голос ALMA (TTS)
- **ffmpeg** — монтаж клипов, наложение музыки

Без съёмки, студии и актёров.

## AI-оптимизация

- `llms.txt` — инструкции для ChatGPT, Claude, Perplexity
- `robots.txt` — разрешения для AI-ботов (GPTBot, ClaudeBot, PerplexityBot)
- `sitemap.xml` — все страницы сайта
- JSON-LD структурированные данные на всех страницах
