# aispirin.ru — Сайт Архитектора нейросотрудников

Личный сайт Андрея Спирина — предпринимателя, создателя AI-сотрудников для бизнеса.

🔗 **Живой сайт:** [aispirin.ru](https://aispirin.ru)

## О проекте

Лендинг с 5 SEO-страницами и AI-оптимизацией. Сделан на React + Vite, задеплоен на Vercel.

**Страницы:** главная, /about/, /services/, /cases/, /contact/

**AI-оптимизация:**
- `llms.txt` — инструкции для ChatGPT, Claude, Perplexity
- `robots.txt` — разрешения для AI-ботов (GPTBot, ClaudeBot, PerplexityBot)
- `sitemap.xml` — 6 страниц
- JSON-LD структурированные данные на всех страницах

## Стек

`React` · `Vite` · `CSS` · `Vercel`

## Запуск локально

```bash
npm install
npm run dev
```
